# Ignis farm artwork

Original pixel artwork authored through Aseprite's Lua scripting API. No generated landscape images are used by the app.

- `farm-scene.aseprite`: layered 256×128 scene; eight named layers for landscape and objects.
- `farmer.aseprite`: editable 16×24 girl with bangs, no hat, a dark outfit, and four walk frames.
- `create-scene.lua` and `create-farmer.lua`: reproducible source generators.
- Runtime exports live in `apps/web/public/farm/`.

From the project root on macOS, regenerate the scene:

```sh
/Applications/Aseprite.app/Contents/MacOS/aseprite --batch \
  --script-param "source=$PWD/art/farm/farm-scene.aseprite" \
  --script-param "export=$PWD/apps/web/public/farm/farm-scene.png" \
  --script-param "trees=$PWD/apps/web/public/farm/tree-canopies.png" \
  --script art/farm/create-scene.lua
```

Re-running a generator replaces its artwork with the scripted version. To retain manual edits, export the edited `.aseprite` with its Sky layer excluded instead:

```sh
/Applications/Aseprite.app/Contents/MacOS/aseprite --batch \
  --ignore-layer "01 Sky" --ignore-layer "Tree canopies" art/farm/farm-scene.aseprite --save-as apps/web/public/farm/farm-scene.png
```

The scene uses the existing 256×128 map coordinates. The cottage hotspot is x105–151/y17–57; beds sit at x24,100,176/y98. Keep these aligned with `InteractiveFarm.tsx` when moving objects. The growing plant sprites remain live layers drawn by React; they are not baked into the static scene. No Git repository has been initialized.

`decorations.aseprite` holds the porch-light, flag and flowers in three frames, generated by `create-decorations.lua` and exported as a horizontal sheet at `apps/web/public/farm/decorations.png`.

The runtime scene PNG omits layer 01 Sky. The web app supplies live Bahia-time lighting; keep the layer visible in the editable source if useful while drawing.

`sky-clouds.aseprite` is the transparent, shaded pixel-cloud overlay made by `create-sky.lua` and exported as `apps/web/public/farm/sky-clouds.png`. The landscape layer now contains a shaded oak and tiered pine with clustered highlights and bark details.

Export the canopy layer independently after manual edits: `aseprite --batch --layer "Tree canopies" art/farm/farm-scene.aseprite --save-as apps/web/public/farm/tree-canopies.png`. Trunks stay in Landscape; the runtime animates only the separate canopy image.

Artwork now uses a small console palette: charcoal fills, slate silhouettes, pale one-pixel outlines and sparse pink details. Buildings and trees are drawn as outlined shapes, with sparse ground texture and thin cloud contours. Sources and exports contain this palette directly; no filter is applied.
