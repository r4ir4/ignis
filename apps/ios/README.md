# iPhone and iPad app

Use Swift and SwiftUI in one iOS application project supporting both iPhone and iPad. Share models, networking and reusable views; tailor navigation and layouts to each device and available window size.

This folder will contain the Xcode project, Swift source, app assets and app-specific tests when development starts. No Xcode project or application code has been generated yet.

The native app will use the shared API. Its authentication, local persistence and synchronization approach must be defined before implementation.
